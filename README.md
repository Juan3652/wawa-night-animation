## How to Use

### Web Browser
1. Open `index.html` in any modern browser
2. The animation will start automatically
3. Runs at 60 FPS

### TheoTown Integration
1. Extract the ZIP file into your TheoTown game mods folder
2. The animation data is compatible with TheoTown building configurations
3. Use the `animation-config.json` settings for in-game placement

## Customization

Edit `animation-config.json` to modify:
- Colors and lighting
- Animation speed
- Effect toggles
- Game-specific settings
